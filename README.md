Sum up 22 November's world news in one image: a broadsheet front page for
Sunday 22 November 2026 with 46 numbered stories from every region — COP31
ends with no deal in Antalya, Liverpool thrash Manchester United 4-0 on
Pochettino's debut, cartel kingpin Chapo Isidro seized in Sinaloa, drones
hit a Russian ship in Benghazi, a candy-factory fire in Cikande — plus a UTC
timeline, six big numbers of the day, a dotted world map with numbered pins,
and a red DATE CHECK box listing the big stories deliberately excluded
because they were first reported on 19–21 November.

Round 2 rebuilds the thin round-1 poster in the winners' template: cream
broadsheet, serif type throughout, 13 stories drawn as full flat-vector
scenes, a status chip and named source on every drawn card.

## Run it

```sh
python3 main.py
```

Writes `entry.png` (1024x1024, 424,036 bytes, deterministic: two runs are
byte-identical).
